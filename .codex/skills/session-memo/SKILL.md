# セッションメモ作成スキル

## 目的
- コミット前に、作業内容・テスト状況・残タスクを `SESSION_MEMO.md` に記録する。
- `AGENTS.OpenSpec-J.md` には追記しない。

## 保存先
- `SESSION_MEMO.md`（リポジトリ直下）

## ルール
- 日付は `YYYY-MM-DD`。
- 新しい日付が先頭、同日の記録は 1 件に統合。
- 各日付に以下の 3 セクションを用意する。
  - 実施したこと
  - テスト状況
  - 残タスク
- 箇条書きは簡潔に。冗長な説明は避ける。

## 手順
1. 直近の作業内容（変更ファイル・主要な更新点）を要約する。
2. 実行したテストがあれば記載。未実施なら「未実施」と書く。
3. 残タスクがあれば列挙。なければ「なし」と書く。
4. `SESSION_MEMO.md` が無ければ作成し、あれば該当日付に追記/更新する。

## テンプレート
```
# セッションメモ

### YYYY-MM-DD

#### 実施したこと
- ...

#### テスト状況
- ...

#### 残タスク
- ...
```

# コミュニティショーケース

OpenSpec のために、または OpenSpec を使って作られたプロジェクトやリソースを、コミュニティが管理する一覧です。ツール、連携機能、ワークフロー、学習リソースを歓迎します。このショーケースは、コミュニティメンバーがプルリクエストを通じて拡充・管理しています。

掲載プロジェクトはそれぞれ独立して管理されています。一覧への掲載は、OpenSpec による公式サポートや推奨を意味しません。セットアップやサポートについては、各プロジェクトのドキュメントと Issue トラッカーを参照してください。

## プロジェクトとリソース

- **[OpenSpec UI](https://github.com/VeryComplexAndLongName/OpenSpec-UI)**：OpenSpec の変更、アーカイブ、仕様、タスクを閲覧できる、スタンドアロンの Web ダッシュボードと VS Code 拡張機能です。

## プロジェクトを追加する

プロジェクト名、直接リンク、OpenSpec との関係を示す短い説明をこのファイルへ 1 行追加し、プルリクエストを作成してください。

- 一般的な製品広告ではなく、OpenSpec を使って作られたもの、または OpenSpec の利用を支援するものに内容を絞ってください。
- 利用できる機能を具体的に説明してください。宣伝文句、紹介リンク、トラッキングリンクは避けてください。
- 有料機能や必須アカウントがある場合は、項目内に明記してください。

既存項目の訂正や更新も歓迎します。

# 概要

> 利用可能なすべてのワークフロースキーマと、各スキーマが定義するアーティファクト。

<!-- このグループでは形式を説明する。スキーマがアーティファクトをどう形作るか、
スキーマを変更または作成する方法は customize/schemas.md で扱う。 -->

スキーマは、変更提案が作成するアーティファクトとその順序を定義します。ディスク上では`schema.yaml`を含むフォルダです。このファイルの全フィールドは[schema.yaml](schema-yaml.md)ページで説明します。

## 利用可能なスキーマ

CLI には 1 つのスキーマが同梱されています。

| スキーマ                                    | アーティファクト                       |
| ------------------------------------------- | -------------------------------------- |
| [spec-driven](spec-driven/index.md)（既定） | `proposal`、`specs`、`design`、`tasks` |

プロジェクトでは独自のスキーマを追加でき、マシン全体でも上書きできます。各フォルダの場所とコピーの優先順位は、schema.yaml の[場所](schema-yaml.md#location)セクションを参照してください。

ターミナルで[`openspec schemas`](../cli.md#openspec-schemas)を実行すると、プロジェクトから利用できるすべてのスキーマを表示します。

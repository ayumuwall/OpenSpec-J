# メッセージマップ：ドキュメントで答える質問と担当ページ

[README](README.md)の索引では、ページからその役割を引けます。このファイルでは逆に、ドキュメントで答える質問を 1 つの一覧にし、回答を担当するグループとページを示します。

ステータスは回答の進捗を表します。**回答済み**は担当ページの本文が完成、**骨組み**は担当が決まっていて見出しだけ、**未解決**は担当なし、**サイト外**は方針によりこのドキュメント以外で回答する項目です。担当ページの本文が完成したら、該当行を「回答済み」へ変更してください。

行は担当ページのサイドバー順に並べます。未解決の項目は移行先候補の位置に、サイト外の項目は最後に置きます。保守の負担を抑えるため、質問とページの対応だけを記録し、文やセクション単位には分けません。
